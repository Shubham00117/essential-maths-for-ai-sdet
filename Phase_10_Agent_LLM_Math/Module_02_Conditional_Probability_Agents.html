🎯 Module 02: Conditional Probability for Agents

1️⃣ Topic: Conditional Probability

Conditional Probability = The probability of event A happening given that event B has already happened.

In simple terms: "How confident should I be about X, knowing what I know now?"
P(A | B) = P(A AND B) / P(B)

Read as: "Probability of A, given B"

2️⃣ Why This Matters (AI / Agent Context)

🎯 Where you'll see this in AI systems:

• LLM Token Generation: P(next_token | context) — entire LLM output is conditional

• Agent Tool Selection: P(tool_success | user_intent, previous_results)

• Retry Logic: P(success | already_failed_N_times) — should we retry?

• Fallback Routing: If primary fails, what's P(secondary_works | primary_failed)?

3️⃣ Core Concept (Simple Language)

Updating Beliefs with Evidence

🏥 Classic Example: Medical Test

Disease rate: 1 in 1000 (0.1%)

Test accuracy: 99%

You test positive. Do you have it?


In 1000 people: 1 true positive + 10 false positives (1% of 999)
P(disease | positive) = 1/11 ≈ 9%!
Context (base rate) matters more than raw accuracy!

Bayes' Theorem

P(A | B) = P(B | A) × P(A) / P(B)

Posterior = Likelihood × Prior / Evidence

🧠 Understanding Each Term

Term What It Means AI Example
P(A) - Prior Belief before evidence P(user wants code) = 30%
P(B|A) - Likelihood Evidence probability if hypothesis true P("function" | wants code) = 80%
P(B) - Evidence Overall evidence probability P("function" appears) = 15%
P(A|B) - Posterior Updated belief after evidence P(wants code | "function") = higher!

4️⃣ Probability → Agent Logic

Concept Agent Decision Pattern
P(A | B) IF B observed, calculate new confidence in A
Prior P(A) Default confidence = 50%
Threshold Decision IF confidence > 70% THEN proceed
Confidence Decay After each failure, confidence *= 0.5

5️⃣ Logical Flow (How Agents Decide)

Confidence-Based Decision Making

DECISION ZONES: confidence >= 70% → PROCEED (confident enough) 30% <= confidence < 70% → ASK CLARIFICATION confidence < 30% → FALLBACK (too uncertain) CONTEXT MODIFIERS: IF user intent is clear: confidence *=1.2 (boost) IF recent error occurred: confidence *=0.7 (penalty) IF query is outside domain: confidence *=0.5 (big penalty)

Retry Logic with Decaying Probability

P(success | attempt N) = base_rate × (decay_factor ^ N) EXAMPLE WITH base=0.8, decay=0.5: Attempt 0: 0.8 × 1 = 80% Attempt 1: 0.8 × 0.5 = 40% Attempt 2: 0.8 × 0.25 = 20% Attempt 3: 0.8 × 0.125 = 10% DECISION: IF P(success) > 10% → RETRY, ELSE → GIVE UP

6️⃣ AI / GenAI Application

LLM Token Generation:

Input: "The cat sat on the ___"

P("mat" | context)  = 0.45  ← most likely
P("floor" | context) = 0.25
P("dog" | context)   = 0.05
P("moon" | context)  = 0.001  ← unlikely

The LLM picks based on these conditional probabilities!
🎯 Agent Decision Framework:
1. Start with prior belief
2. Observe evidence
3. Update belief using Bayes
4. Compare to threshold → decide action

7️⃣ Testing / SDET Angle

🧪 Key Test Scenarios

Test Type What to Verify
Threshold Boundary At 69% → different action than at 71%
Context Modifiers With error → lower confidence than without
Probability Bounds All probabilities stay within 0-1
Decay Tests Confidence decreases with each failure

8️⃣ Common Mistakes

❌ Ignoring base rates: 99% accurate test on 0.1% disease = only 9% after positive!
❌ Treating 80% as certainty: 20% failure still happens 1 in 5 times!
❌ Confusing P(A|B) with P(B|A): They're completely different!

9️⃣ One-Line Summary

💡 Conditional probability lets agents think "Given what I know now, what should I do?" — powering smart retry, fallback, and confidence routing.
