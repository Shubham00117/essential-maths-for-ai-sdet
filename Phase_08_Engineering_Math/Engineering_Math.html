Logarithms

Logarithm is the inverse of exponentiation.

If bˣ = y, then log_b(y) = x
"What power do I raise b to, to get y?"
log_b(y) = x means b^x = y

Example: log₂(8) = 3 because 2³ = 8

Common Logarithm Types:

log (Base 10) Common logarithm

log(100) = 2
(10² = 100)
ln (Base e) Natural logarithm

e ≈ 2.718
Used in calculus
log₂ (Base 2) Binary logarithm

log₂(8) = 3
Used in CS!

Logarithm Rules:

Rule Formula Example
Product log(a×b) = log(a) + log(b) log(2×4) = log(2)+log(4)
Quotient log(a/b) = log(a) - log(b) log(8/2) = log(8)-log(2)
Power log(aⁿ) = n × log(a) log(2³) = 3×log(2)
Base Change log_b(x) = log(x)/log(b) log₂(8) = log(8)/log(2)

📝 Example: Solve log₂(32)

1Ask: 2 to what power = 32?
22¹=2, 2²=4, 2³=8, 2⁴=16, 2⁵=32
log₂(32) = 5

Binary Number System

Binary uses only 2 digits: 0 and 1

Computers use binary because circuits have two states: ON (1) and OFF (0)

Place Values in Binary:

Position 7 6 5 4 3 2 1 0
Value 128 64 32 16 8 4 2 1
Power 2⁷ 2⁶ 2⁵ 2⁴ 2³ 2² 2¹ 2⁰

Binary to Decimal:

📝 Convert 1011 (binary) to decimal

1Write place values: 8, 4, 2, 1
2Match with binary: 1×8 + 0×4 + 1×2 + 1×1
3Calculate: 8 + 0 + 2 + 1 = 11
1011₂ = 11₁₀

Decimal to Binary:

📝 Convert 13 (decimal) to binary

1Divide by 2, track remainders:
13 ÷ 2 = 6 remainder 1
6 ÷ 2 = 3 remainder 0
3 ÷ 2 = 1 remainder 1
1 ÷ 2 = 0 remainder 1
2Read remainders bottom-up: 1101
13₁₀ = 1101₂

Big O Notation

Big O describes how an algorithm's time/space grows as input size increases.

It measures worst-case efficiency. Essential for software testing & performance!

Common Time Complexities:

Big O Name Example n=1000
O(1) Constant Array access 1
O(log n) Logarithmic Binary search ~10
O(n) Linear Simple loop 1,000
O(n log n) Linearithmic Merge sort ~10,000
O(n²) Quadratic Nested loops 1,000,000
O(2ⁿ) Exponential Recursive fibonacci HUGE!

O(1) - Constant

function getFirst(arr) {
  return arr[0];
}
Always takes same time regardless of array size

O(n) - Linear

function findMax(arr) {
  for each item in arr:
    check if max
}
Time grows linearly with input size

O(n²) - Quadratic (Nested Loops)

for i in range(n):
  for j in range(n):
    print(i, j)
If n=10, runs 100 times. If n=100, runs 10,000 times!
✨ Rule of Thumb:
• O(1), O(log n) → Excellent
• O(n), O(n log n) → Good
• O(n²) → Acceptable for small data
• O(2ⁿ), O(n!) → Usually too slow

Exponents & Powers

Exponent tells how many times to multiply a number by itself.
aⁿ = a × a × a × ... (n times)

Exponent Rules:

Rule Formula Example
Product aᵐ × aⁿ = aᵐ⁺ⁿ 2³ × 2² = 2⁵ = 32
Quotient aᵐ ÷ aⁿ = aᵐ⁻ⁿ 2⁵ ÷ 2² = 2³ = 8
Power of Power (aᵐ)ⁿ = aᵐˣⁿ (2²)³ = 2⁶ = 64
Zero Power a⁰ = 1 5⁰ = 1
Negative Power a⁻ⁿ = 1/aⁿ 2⁻³ = 1/8

📝 Simplify: 2⁴ × 2³ ÷ 2²

1Add exponents for multiplication: 2⁴⁺³ = 2⁷
2Subtract for division: 2⁷⁻² = 2⁵
3Calculate: 2⁵ = 32
Answer = 32

Sequences & Series

Arithmetic Sequence

Each term differs by a constant value (d).
Example: 2, 5, 8, 11, 14 (d = 3)
nth term: aₙ = a₁ + (n-1) × d

Sum: S = n/2 × (first + last)

📝 Find 10th term of: 3, 7, 11, 15...

1First term (a₁) = 3, Common difference (d) = 4
2a₁₀ = 3 + (10-1) × 4 = 3 + 36 = 39
10th term = 39

Geometric Sequence

Each term is multiplied by a constant ratio (r).
Example: 2, 6, 18, 54 (r = 3)
nth term: aₙ = a₁ × r^(n-1)

📝 Find 5th term of: 2, 6, 18...

1First term = 2, Ratio = 3
2a₅ = 2 × 3⁴ = 2 × 81 = 162
5th term = 162

Matrices Basics

A Matrix is a rectangular array of numbers arranged in rows and columns. It allows us to store complex datasets in a structured way.

Matrix Notation & Structure:

Matrix A (2×3)
[ 1  2  3 ]
[ 4  5  6 ]

2 rows × 3 columns
Element Notation

aij = element at row i, column j

a12 = 2 (row 1, col 2)
a23 = 6 (row 2, col 3)

Types of Matrices:

Row Vector (1×n)
[ 1 2 3 ]

Horizontal array
Column Vector (m×1)
[ 1 ]
[ 2 ]
Vertical array
Square Matrix (n×n)
[ 1 2 ]
[ 3 4 ]
Equal rows & cols

Special Matrices:

Identity Matrix (I)

[ 1  0 ]
[ 0  1 ]
1s on diagonal, 0s elsewhere

Zero Matrix (0)

[ 0  0 ]
[ 0  0 ]
All elements are zero

Basic Operations:

1. Matrix Addition

Add elements at same positions
[1 2] + [3 4] = [4 6]

2. Scalar Multiplication

Multiply every element by a number
2 × [1 2] = [2 4]

3. Transpose (Aᵀ)

Swap rows and columns.
Original
[ 1 2 3 ]
[ 4 5 6 ]
Transpose
[ 1 4 ]
[ 2 5 ]
[ 3 6 ]
