# 🧮 Essential Mathematics for AI-SDET

A structured, self-paced mathematics curriculum designed for **Software Development Engineers in Test (SDETs)** transitioning into **AI/ML testing and Agentic QA**. Covers everything from basic arithmetic to the math behind LLMs, RAG pipelines, and agent architectures.

---

## 📖 Overview

This repository is a comprehensive **10-phase math course** that bridges the gap between traditional QA engineering and modern AI testing. Each phase builds on the previous one, starting from number theory and progressing to the mathematics powering LLMs, embeddings, and autonomous agents.

> 💡 **Why this matters for SDETs:** Understanding the math behind AI systems enables you to write more meaningful tests, validate model behavior at a deeper level, and reason about edge cases in AI-powered applications.

---

## 📚 Curriculum

| Phase | Topic | Modules |
|-------|-------|---------|
| **Phase 01** | Number Theory & Arithmetic | Print Numbers, Comparisons, Even/Odd, Number Operations, Advanced Operations, Decimal Comparisons |
| **Phase 02** | Ratios & Percentages | Ratios, Percentages, Proportional Reasoning, Time-Speed-Distance |
| **Phase 03** | Algebra | Variables & Expressions, Simple Equations, Substitution, Inequalities, Absolute Values |
| **Phase 04** | Spatial Thinking | Basic Geometry, Coordinate Systems, Distance Calculations |
| **Phase 05** | Sets & Logic | Set Theory, Set Operations, Boolean Logic & Truth Tables |
| **Phase 06** | Statistics | Central Tendency, Spread & Standard Deviation, Data Analysis & Distribution |
| **Phase 07** | Probability | Core Probability Concepts |
| **Phase 08** | Engineering Math | Applied Mathematics for Engineering |
| **Phase 09** | CS Math Essentials | Computer Science Mathematical Foundations |
| **Phase 10** | Agent & LLM Math | Graph Theory, Conditional Probability for Agents, Embeddings & Cosine Similarity, Optimization Thinking, Information Theory, RAG & DAG Architectures, LLM Training Fundamentals |

## 🚀 Getting Started

### Prerequisites
- Python 3.x (for running exercises)
- Any modern web browser (for viewing HTML notes)

### How to Use
1. Clone the repository:
   ```bash
   git clone https://github.com/Shubham00117/essential-maths-for-ai-sdet.git
   ```
2. Start from **Phase 01** and work through the exercises sequentially
3. Open the `.html` files in your browser for interactive notes
4. Run Python exercises:
   ```bash
   python Excercise/M01_PrintNumbersForwards.py
   ```
